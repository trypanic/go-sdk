# AGENTS.md

## Global language rule

Interact in Spanish; write and build in English. User-visible chat, explanations,
questions, plans, progress updates and tool-call descriptions are Spanish. Code,
identifiers, comments, tests, configuration, files, documents, task briefs, commits,
branches, issues and pull requests are English. Preserve literal paths, commands
and identifiers in Spanish messages. An explicit language exception applies only
to the output it names.

Operational guide for agents consuming or extending `github.com/trypanic/go-sdk/v2`.
Package READMEs are the authoritative detailed contracts. See the
[v2 API migration](./docs/v2-api-migration.md) for approved removals and renames.

- Module: `github.com/trypanic/go-sdk/v2`.
- Language floor: Go `1.26.1`. Use the latest supported patched Go 1.26 (at least 1.26.10) or Go 1.27; see [compatibility](./README.md#supported-toolchains). The development pin is `.prototools`.
- License: [MIT](./LICENSE) · status: [README.md](./README.md) · release notes: [CHANGELOG.md](./CHANGELOG.md) (generated by release-please) · security policy: [SECURITY.md](./SECURITY.md).

## 0. Import path vs. package name (read first)

Public package identifiers match their directory names. Import `postgres` and
call `postgres.New`; import `mongo` and call `mongo.New`. The former identifiers
`database` and `mongodb` are removed. The former SDK `slices` package is now
`batch`; use `batch.Chunk` and `batch.MergeUniqueStrings`.

Alias the SDK gRPC package as `sdkgrpc` when also importing
`google.golang.org/grpc`. Alias the upstream MongoDB driver as `mongodriver`
when also importing the SDK `mongo` package. The SDK remains one module; a
binary links only its imported packages and their dependencies.

## 2. Universal conventions

### 2.1 Errors

SDK-classified operation failures normally return an `error` containing a
`*errorkit.AppError`, with code, HTTP status and retryability. Do not assume every
error has that dynamic type. Upstream escape hatches (`*http.Client`, pgx pools,
Mongo driver, gRPC connections), user handlers/callbacks and generated gRPC clients
retain upstream errors. Hertz `Shutdown` can return raw lifecycle errors;
OTLP provider cleanup can return provider errors. `grpc.ToStatus` returns gRPC
statuses; `grpc.FromStatus` classifies statuses but preserves non-status errors.

Use `errorkit.As(err)` and `errorkit.HasCode(err, code)` across wrapped/joined
chains; typed-nil errors do not hide valid sibling errors. Preserve an existing
AppError and wrap external causes once at a boundary. Register service-specific
codes with `errorkit.MustRegister` in service initialization. The generic
`ERR_EXTERNAL_*` codes belong to `errorkit`, without importing `httpclient`.

`NewError` captures a stack. `NewWithoutStack` deliberately omits it; validators
use this for expected input rejection, while invalid validator configuration
retains a stack. Identity, metadata and causes remain available.

Retryability starts with `Metadata.Retriable`. `httprequest` additionally requires
safe replay: an idempotent method, an idempotency key, or a failure before the
original connection was established. A redirected POST is not safe merely because
a later dial failed. `RetryNonIdempotent` explicitly accepts duplicate side effects.
HTTP and messaging transports share bounded full jitter; public backoff config
units and attempt semantics are documented per package. Messaging retry policies
have an explicit 15-minute elapsed budget in addition to context/attempt bounds.

### 2.2 Tracing

`httprequest`, `llmclient` and `mongo` return concrete clients with integrated
tracing: `New` uses the global OTel provider, `NewWithoutTracing` disables it,
and `NewWithInstrumenter` accepts the caller's instrumenter (nil disables it).
`WrapWithInstrumenter` returns its input unchanged for nil; otherwise it adds a
span and exposes `Unwrap`. Do not wrap an already traced client unless nested
spans are intentional. `httprequest.NewWithOptions` starts untraced; add
`WithInstrumenter(instr)` alongside retry/audit options.

`Instrumenter.TracerProvider()` supports adapters needing the provider itself.
Use `messaging.WithInstrumenter`, `grpc.WithServerInstrumenter`, and
`grpc.WithClientInstrumenter`; nil explicitly disables provider-backed tracing.
The existing tracer/provider options remain available. Hertz's OTel middleware
uses the global provider; the SDK does not claim instrumenter injection there.

PostgreSQL pool constructors do not add spans. `NewStoredProcedure[T]` returns
`*TracedProcedure[T]`; `WrapWithInstrumenter[T]` decorates an untraced procedure.
`Unwrap` exposes the underlying procedure. The caller configures pgx driver tracing.

Use `Instrumenter.Job`, `Batch`, `External`, `Messaging`, and `DB`. HTTP names are
`external.http.<host>.<METHOD>` (empty method means GET), LLM names
`external.llm.execute`, PostgreSQL names `postgres.<routine>.query`, and Mongo
names `mongo.<collection>.<operation>` / `mongo.client.<operation>`. Paths and
models are attributes. Client failures use `telemetry.End`: Error status, a
sanitized exception event and classification attributes. Never put payloads,
credentials, private reasons or resource IDs into span names.

### 2.3 Logging

`logger.Init` alone configures zerolog process globals. It serializes initialization
and atomically publishes the SDK logger; concurrent SDK logging is supported.
Configure global zerolog settings before outside code reads those globals directly.
Prefer explicit `logger.New` instances in libraries/tests. `DetectEnv` defaults
to Prod (JSON/Info); development output is explicit.

Library code should not log an error it returns for the caller to handle;
`httprequest.Do` follows this rule. Choose an explicit logger option first,
then the context logger and global fallback via `logger.CtxOrGlobal(ctx)`.
Use `ErrorCtx` / `WarnCtx` for trace correlation. Outbound audit is opt-in via
`httprequest.WithAuditLog`; the default Hertz server profile includes redacted audit.

Base `logger`, `httprequest` and `llmclient` do not link gRPC through logging.
Import `logger/otlp` explicitly. `otlp.NewProvider` is the error-returning TLS
constructor; construct `otlp.NewWriter` afterwards. The caller closes the provider.
`InitProvider` / `Setup` retain lenient plaintext compatibility behavior.
`logger.Init` and `Config.OTLPWriter` accept `io.Writer`; typed-nil OTLP writers
are tolerated. ANSI presentation constants are private.

### 2.4 Configuration

Environment reads are explicit API choices, including `logger.DetectEnv` and
`logger.Init`. Use `postgres.NewFromEnv` / `NewFromEnvContext` for `POSTGRES_DSN`,
`messaging.NewPubSubFromEnv` / `NewPubSubFromEnvContext` for
`RABBITMQ_TOPOLOGY_FILE`, and `llmclient.ConfigFromEnv` for `LLM_API_KEY` plus
optional `LLM_ENDPOINT`. Plain messaging construction requires `WithTopology`
or `WithTopologyFile`; it does not fall back to the environment.

Use `cfg, err := envs.Load[Config]()` for typed service configuration,
`LoadInto(&cfg)` for an existing struct, or `LoadWithOptions` with an explicit
map/prefix. Errors name fields without exposing environment values.

### 2.5 Body capture / redaction

HTTP bodies are omitted or redacted by default. `WithBodyCapture` opts into
redacted error payloads; `WithRawBodies` bypasses redaction and belongs only in
controlled development. A `BodyRedactor` can impose a custom policy. URLs and
URL-bearing audit headers have sensitive values masked. Use `PublicJSON` or
`Public` for responses; `PrettyJSON` is diagnostic output for logs only.

### 2.6 Concurrency and lifecycle

Share clients per logical upstream. Context constructors bound initial network
setup without taking ownership of the resulting client's lifetime. Close owned
clients at process scope with a fresh bounded shutdown context when needed.
A Mongo client passed to `NewFromClient` is borrowed: its original owner calls
Disconnect; the adapter's Close does not disconnect it. Engine/Database/Unwrap
escape hatches retain the upstream ownership rules.

HTTP contexts, Mongo cursors, backoff schedules and configurable test fakes have
narrower concurrency contracts; read their package docs. For `batch.Chunk`, size
must be positive; non-positive sizes return nil. Chunks share input elements but
have clipped capacity, so appending cannot overwrite the next chunk.

## 3. Canonical service bootstrap

This compiles against the SDK. Supply valid service configuration and replace
the wait with the application's server/worker loop. Network setup is bounded;
shutdown uses a separate context so cancellation does not skip flushing.

```go
package main

import (
    "context"
    "os"
    "os/signal"
    "syscall"
    "time"

    "github.com/trypanic/go-sdk/v2/errorkit"
    "github.com/trypanic/go-sdk/v2/httpclient"
    "github.com/trypanic/go-sdk/v2/httprequest"
    "github.com/trypanic/go-sdk/v2/logger"
    "github.com/trypanic/go-sdk/v2/logger/otlp"
    "github.com/trypanic/go-sdk/v2/messaging"
    "github.com/trypanic/go-sdk/v2/postgres"
    "github.com/trypanic/go-sdk/v2/telemetry"
)

func main() {
    ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
    defer stop()
    if err := run(ctx); err != nil {
        logFailure(ctx, err, "service failed")
        os.Exit(1)
    }
}

func run(ctx context.Context) error {
    const serviceName = "my-service"
    startup, cancel := context.WithTimeout(ctx, 20*time.Second)
    defer cancel()

    provider, err := otlp.NewProvider(startup, otlp.Config{
        ServiceName: serviceName,
        Endpoint: os.Getenv("OTEL_COLLECTOR_ENDPOINT"), // TLS by default
    })
    if err != nil { return err }
    defer func() {
        shutdown, cancel := context.WithTimeout(context.Background(), 5*time.Second)
        defer cancel()
        if err := provider.Close(shutdown); err != nil {
            logFailure(shutdown, err, "log provider shutdown failed")
        }
    }()
    _, cleanup := logger.Init(serviceName, "0.1.0", otlp.NewWriter(serviceName))
    defer cleanup.Close()

    instr := telemetry.NewInstrumenter(telemetry.InstrumenterConfig{ScopeName: serviceName})
    httpClient := httpclient.NewDefaultClient()
    defer httpClient.CloseIdleConnections()
    requester := httprequest.NewWithInstrumenter(httpClient, instr)

    pool, err := postgres.NewFromEnvContext(startup, postgres.Config{})
    if err != nil { return err }
    defer pool.Close()

    // Topology: explicit options win; only this FromEnv family reads the env file.
    mq, err := messaging.NewPubSubFromEnvContext(startup, os.Getenv("RABBITMQ_URL"),
        messaging.WithInstrumenter(instr))
    if err != nil { return err }
    defer func() {
        if err := mq.Close(); err != nil { logFailure(ctx, err, "messaging shutdown failed") }
    }()

    _ = requester // inject into the application's handlers
    <-ctx.Done()
    return nil
}

func logFailure(ctx context.Context, err error, message string) {
    appErr, ok := errorkit.As(err)
    if !ok { appErr = errorkit.NewError(errorkit.ERR_INTERNAL).With(errorkit.WithWrapped(err)) }
    logger.ErrorCtx(ctx, appErr, message)
}
```

## 4. Idiomatic error handling

```go
result, err := svc.Do(ctx, input)
if err != nil {
    if appErr, ok := errorkit.As(err); ok {
        logger.ErrorCtx(ctx, appErr, "svc.Do failed")
        return appErr
    }
    wrapped := errorkit.NewError(errorkit.ERR_INTERNAL).With(errorkit.WithWrapped(err))
    logger.ErrorCtx(ctx, wrapped, "svc.Do failed")
    return wrapped
}
```

Wrap once at an external boundary, keep specific codes and match with `HasCode`.
For HTTP handlers prefer `httpserver.ReplyError(c, err)` or serialize
`appErr.PublicJSON()` with a suitable status from `httpserver.StatusFor(err)`.
Use `grpc.ToStatus` on outbound handler errors and `grpc.FromStatus` on received
statuses. Do not expose `PrettyJSON`, stack traces or wrapped driver diagnostics.

## 5. Anti-patterns (do not write this code)

- Constructing an HTTP client, pool or messaging connection per request.
- Replacing a classified error with generic ERR_INTERNAL, or using a direct type assertion that misses wrappers.
- Logging inside every retry attempt and again at the caller.
- Retrying POST/PATCH after uncertain delivery without an explicit idempotency contract.
- Reading environment variables implicitly in SDK constructors.
- Raw bodies or `ioutils` on production data paths.
- Importing `httpserver/hertz` from non-server code or `logger/otlp` solely for base logging.
- Closing a borrowed Mongo driver client from its wrapper.
- Using `telemetry.InitTracer` in new code; it is a compatibility API.

## 6. Testing conventions

Keep unit tests next to source and external-package examples for public APIs.
`go test -short ./...` must not contact external services; use local transports,
loopback fixtures or fakes. Infrastructure tests require `integration` build tags
or the documented `-short` skip. Accept narrow consumer interfaces such as
`httprequest.Requester`, `llmclient.Provider` or `messaging.Broker`; Registry and
Instrumenter are concrete types, not mock interfaces.

Use `stretchr/testify` assertions where helpful and check error codes/causes,
not incidental error text. Public doubles are available in `httpservertest`,
`mongotest` and `messagingtest`; unset callbacks fail fast. Assert the HTTP
recorder's `Err` after handlers. Keep callback synchronization explicit.

## 7. Quality gates (run before committing)

```bash
task check  # unit/race tests, build/vet, staticcheck/Semgrep, govulncheck, tidy checks, hooks
task lint   # informational golangci-lint
```

`task check` uses the active toolchain; CI also tests the supported Go matrix.
For scoped development run `task test -- postgres` and
`go test -race -short ./postgres/...`. Run `task release:check` from a clean tree
before exported API changes. Use Conventional Commits, with `!` and a
`BREAKING CHANGE:` paragraph for approved incompatible changes. Never edit
CHANGELOG.md or `.release-please-manifest.json`; release-please owns them.

Dependency updates use `task deps:update -- <pkg>` and are serialized. During
the audit, go.mod/go.sum and the `/v2` module migration belong only to R-DEPS.
Reports go to `.staticanalysis/`; follow [SECURITY.md](./SECURITY.md) for tool
versions and warning triage. Report vulnerabilities privately through GitHub's
private vulnerability reporting channel, not a public issue.

## 8. Working inside this repo

Read the target README, errorkit registration contract, telemetry contract and
SECURITY.md before implementation. New public packages need package GoDoc,
README, executable examples, concurrency/lifecycle documentation and entries
in this guide and the root package map. Keep exported interfaces at consumer
boundaries; return concrete adapters where documented.

Upstream API types are intentional for `net/http`, pgx, MongoDB driver, gRPC,
OTel and explicitly documented configuration/escape hatches. Preserve their
versioned contracts. `algorithms.Backoff` is SDK-owned; do not expose the
implementation's cenkalti type. Do not introduce new exported signatures tied
to unstable v0.x dependencies without an explicit API decision. Keep Hertz and
OTLP dependencies isolated in their adapter packages.
