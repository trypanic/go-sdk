## Blocking finding — HIGH: URL headers leak secrets in both audit directions

`internal/redact/headers.go:49–53` returns `Referer` and `Location` unchanged.
Outbound audit serializes them at `httprequest/audit.go:31–42` when
`WithAuditLog()` is enabled. Inbound audit repeats the policy at
`httpserver/hertz/server.go:193–200,241–245` and is enabled by
`DefaultServerOptions()`. Body capture is disabled in these reproductions.

Both logs contain the synthetic value `FINAL_REVIEW_SECRET` verbatim:

```text
request.headers.Referer = https://example.test/?token=FINAL_REVIEW_SECRET
response.headers.Location = https://example.test/callback?code=FINAL_REVIEW_SECRET
```

This violates R-006/R-008/R-013. Both reviewer reproductions exit **1**.
The orchestrator independently reran the outbound reproduction: exit **1**,
with both raw URL values in the `http.audit.outbound` JSON event.

Required correction: use one shared policy to sanitize or mask URL-bearing
headers in both directions, including malformed URLs. Add regressions for
both directions before rerunning the final gates. No further remediation
was performed because the review-loop cap requires an owner decision.

### Outbound

```go
package httprequest
import (
 "bytes"
 "net/http"
 "net/http/httptest"
 "strings"
 "testing"
 "github.com/rs/zerolog"
 "github.com/trypanic/go-sdk/logger"
)
func TestFinalReviewURLHeadersDoNotLeak(t *testing.T) {
 const secret = "FINAL_REVIEW_SECRET"
 srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter,r *http.Request) {
  w.Header().Set("Location", "https://example.test/callback?code="+secret)
  w.WriteHeader(http.StatusFound)
 }))
 defer srv.Close()
 var logs bytes.Buffer
 zl := zerolog.New(&logs)
 ctx := logger.WithLogger(t.Context(), &zl)
 client := srv.Client()
 client.CheckRedirect = func(*http.Request, []*http.Request) error {return http.ErrUseLastResponse}
 _ = NewWithOptions(client, WithAuditLog(), WithRetryConfig(RetryConfig{MaxRetries:1})).Do(ctx, RequestConfig{Method:"GET",URL:srv.URL, Headers:map[string]string{"Referer":"https://example.test/?token="+secret}},nil)
 if strings.Contains(logs.String(),secret) { t.Fatalf("URL header secrets logged: %s", logs.String()) }
}
```
